# مولّد الشهادات 🎓

أداة مجانية تعمل في المتصفح لتوليد **شهادة لكل طالب** تلقائياً من ملف Excel، مرتبة حسب الصف.

## الفكرة
1. ارفع صورة الشهادة الفارغة.
2. أضف المتغيرات (اسم الطالب، الصف، التقدير، اسم المعلم، ...) واسحبها لمكانها على الشهادة.
3. اختر الخط واللون والحجم.
4. ارفع ملف Excel فيه بيانات الطلاب — يُربط كل متغير بعموده تلقائياً.
5. اضغط **توليد الشهادات** ← ملف ZIP فيه مجلد لكل صف + ملف PDF لكل صف جاهز للطباعة.

## المميزات
- 6 قوالب شهادات جاهزة (كلاسيكي ذهبي، عصري، للأطفال، إسلامي، أنيق كحلي، بسيط).
- واجهة عربية وإنجليزية، وتعمل على الكمبيوتر والجوال.
- تراجع وإعادة (Ctrl+Z / Ctrl+Y) وجولة تعريفية للمستخدم الجديد.
- سحب وإفلات الحقول على الشهادة مع محاذاة تلقائية.
- أكثر من 25 خطاً عربياً وإنجليزياً، مع إمكانية رفع خطك الخاص.
- تصغير تلقائي للأسماء الطويلة لتتسع في مكانها.
- ترتيب ذكي للصفوف (الأول ← الثاني ← ... ← الثاني عشر).
- تصدير PNG / JPG / PDF.
- حفظ التصميم في ملف لإعادة استخدامه.
- **الخصوصية:** كل شيء يعمل على جهازك، ولا تُرفع بيانات الطلاب إلى أي خادم.

## ملف Excel
- الصف الأول = أسماء الأعمدة، وكل طالب في سطر.
- يجب وجود عمود للصف (مثل «الصف» أو «الفصل» أو «الشعبة»)، أو ورقة (Sheet) مستقلة لكل صف.
- من Google Sheets: الصق رابط الجدول في خانة «من Google Sheets» واضغط «جلب» (يجب أن يكون الجدول مشاركاً: «أي شخص لديه الرابط ← عارض»). بعد تعديل الجدول اضغط «تحديث البيانات».

## التشغيل
افتح `index.html` في المتصفح (Chrome أو Edge)، أو استخدم النسخة المنشورة على GitHub Pages.
